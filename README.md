# playground-ai

AI Image Editor application integrating OpenAI's DALL-E 2 for sophisticated image editing.

## Features

- Upload capability with local preview
- OpenAI API Integration via direct robust Axios multipart construction
- Built with HTML, Tailwind CSS, Vanilla JS, Node.js, and Express.

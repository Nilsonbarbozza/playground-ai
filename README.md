# VEED AI Playground - Surgical Professional Editor

O Playground AI não é apenas uma ferramenta de geração. Ele é o marco do **Eixo 2**: Um ambiente focado puramente em **Edições em Nível Cirúrgico**, robustas e profissionais.
Aqui o desenvolvedor/designer instrui, marca e conversa com o cérebro da Inteligência Artificial (GPT-4o-mini Vision - *Elite Art Director*) para ditar perfeitamente o design, manipulando Cores HEX reais, Texturas Físicas precisas e protegendo o Background estritamente via *Negative Prompting* agressivo na API da **Stability AI**.

## Features Atuais (Eixo 2)
- ✅ Preview Local e Máscaras Desacopladas com Alpha Perfeito.
- ✅ Roteamento de Intenção Dinâmico (ERASE vs INPAINT).
- ✅ Motor de Visão Computacional (Diretor de Arte GPT) para dissecar materialidade, direção de luz e cor exata.
- ✅ Blindagem Protética de Backgrounds (Evita sangramento visual, clones e distorções estéticas do estilo base).

## Features Futuras Mapeadas
- 🔜 Seletor de Cores Dinâmico na UI (Color Picker).
- 🔜 Box para Upload de Inputs Vetoriais Estáticos (Logos, Marcas D'água) para decalque por máscara direcionada.
